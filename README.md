### 🛒 [TechMart — AI-Powered E-Commerce Platform](https://github.com/George-lab2004/TechMart)

A full-stack electronics store featuring two AI assistants: a shopping assistant for customers and a business analyst for administrators.

**Highlights**
- Built a full-stack application with **38 REST API endpoints**, five database models, and 15 application views.
- Integrated two Google Gemini function-calling assistants for product discovery, cart actions, and business analytics.
- Implemented JWT authentication using HTTP-only cookies, email verification, and OTP-based password recovery.
- Developed product and order management, cart synchronization, and role-protected admin features.
- Added request validation, rate limiting, and safeguards for the demonstration admin account.

**Tech stack:** React, TypeScript, Node.js, Express, MongoDB, Mongoose, Redux Toolkit, RTK Query, Tailwind CSS, Google Gemini.

🔗 [Source Code](https://github.com/George-lab2004/TechMart) · [Live Demo](https://tech-mart-e1dv.vercel.app/)

### 🤖 [ProjectMonitorAI — AI-Powered Project Management Backend](https://github.com/George-lab2004/ProjectMonitorAI)

A backend-focused project management platform featuring AI-powered project auditing, secure APIs, and real-time collaboration infrastructure.

**Highlights**
- Built a Node.js/Express backend with MongoDB and role-based access control.
- Developed an AI auditor powered by Google Gemini, using an **11-function tool registry** to query project metrics dynamically.
- Engineered a four-tier, multi-model fallback pipeline for improved AI request resilience.
- Implemented real-time Kanban synchronization infrastructure using Pusher and private-channel authorization.
- Added scheduled background processing and backend API security measures.

**Status:** Backend completed; frontend development in progress.

**Tech stack:** Node.js, TypeScript, Express.js, MongoDB, Google Gemini, Pusher, Joi.

### 🍽️ [RestaurantHub — ASP.NET Core Ordering System](https://github.com/George-lab2004/RestaurantHub)

An online restaurant ordering application with separate customer and administrator experiences, built with ASP.NET Core MVC.

**Highlights**
- Designed a relational data model using Entity Framework Core Code First and SQL Server.
- Implemented Admin/Customer authorization with ASP.NET Core Identity.
- Built menu and category management, secure image uploads, a session-based cart, and checkout.
- Enforced server-side pricing and stored purchase-time price snapshots.
- Implemented transactional checkout, order ownership checks, and protection against unauthorized order access.
- Added validated order-status transitions, order-status history, request logging, and global exception-handling middleware.

**Tech stack:** C#, ASP.NET Core MVC, Entity Framework Core, SQL Server, ASP.NET Core Identity, LINQ, Bootstrap.

🔗 [Source Code](https://github.com/George-lab2004/RestaurantHub)
